# README media

The repository README is already wired to these two files:

- `all-flows.gif` — project-wide **Load all flows** / overview recording.
- `detail-flow.gif` — focused node / **Detail Flow** recording.

The files currently included are obvious placeholders so the README renders cleanly before the final recordings are available.

To publish your real recordings, simply overwrite the two GIF files and keep the same names. No changes to the root `README.md` are required.

Suggested capture guidelines:

- 1280–1600 px wide before compression;
- crop to the Android Studio Flow Graph area where possible;
- 6–15 seconds per GIF;
- use the All Flows GIF to show project loading, navigation/zoom, and the overall graph;
- use the Detail Flow GIF to show selecting a node, focused causal paths, details, and optionally live activity/timeline behavior.
